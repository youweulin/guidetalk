# kaitalk · Product Vision

> 寫於 2026-04-10 —— 不是行銷文案，是給未來的我看的「我們在做什麼」備忘錄。
> 任何時候做決定之前先回來看這份。

---

## 🎯 一句話定義

**「會講中文，就能跟全世界聊天。」**

英文：**Speak your language. Meet the world.**

日文：**母国語で世界と話そう。**

---

## 🔑 Core Thesis

### kaitalk **不是**語音聊天 App
### kaitalk **是**「**讓不同語言的人能即時對話**」這件事

語音是手段，**翻譯才是產品**。

如果哪天技術允許「**即時讀心術**」效果更好，我們會放棄語音。
如果某天 AR 眼鏡能即時字幕投影，我們會做眼鏡 App。
**語言隔閡的解決**才是 kaitalk 的存在意義，介質會變。

## 🌍 市場演化路徑（執行順序）

```
Phase A (現在 - 6 個月):  台灣 ↔ 日本
Phase B (6-12 個月):       + 韓國 + 香港 + 新加坡（同時區，文化近）
Phase C (12-18 個月):      + 美國 + 加拿大 + 澳洲（英語市場）
Phase D (18-24 個月):      + 歐洲（多語言）
Phase E (24+ 個月):        + 拉美 + 印度 + 東南亞
```

### 為什麼這個順序

- **冷啟動鐵律**：兩端都要在線才能配對
- **跨時區死亡**：太早衝歐洲 = 亞洲晚上 = 歐洲早上 = 沒人在線
- **滾動擴張**：先把 1 個語言對做密 → 自然延伸
- **不要一次衝**：vision 全球，**執行單點**

## 🎭 為什麼從台灣 ↔ 日本起步

### 1. 文化好奇心**雙向真實存在**
- 台灣人對日本文化有強烈好感（旅遊、動漫、料理）
- 日本人對台灣有獨特好感（友善、美食、近）
- 不是想像出來的需求，**有實際的人想做這件事**

### 2. 語言隔閡**真實但不絕望**
- 兩邊很多人會一點對方的語言，但**不敢開口講**
- 翻譯字幕**剛好補上「敢開口」這個門檻**
- 太強的語言關係（中港）不需要翻譯
- 太弱的語言關係（中阿）翻譯品質太差

### 3. 同時區
- 台灣 UTC+8，日本 UTC+9
- 1 小時時差幾乎可以忽略
- 配對佇列**永遠有人在線**

### 4. 創辦人 (你) 對日本市場有 domain knowledge
- 既有的日本旅遊業務
- 對日本用戶心理有感
- 內容（豆知識）寫得比別人好

### 5. 技術成熟
- 中文 STT 在 2026 已經好用（Web Speech API、Apple SpeechAnalyzer）
- 日文 STT 同樣
- 中日翻譯品質**已經不是瓶頸**（Google / DeepL / Apple Translation）

## 🛡️ Anti-Tinder 定位

### kaitalk **絕對不是**

- ❌ 交友軟體
- ❌ 約會 App
- ❌ Dating site
- ❌ 滑卡片
- ❌ 露臉
- ❌ 公開個人資料
- ❌ 「看誰最受歡迎」的虛榮經濟

### kaitalk **是**

- ✅ **「有人陪」的服務**
- ✅ 隨機、輕鬆、不留痕跡
- ✅ 像打電話給陌生人，但不尷尬
- ✅ 對抗孤獨感
- ✅ 讓你覺得「世界上有人在跟我講話」

### 為什麼這個定位重要

- 交友軟體市場已經紅海（Tinder / Bumble / Hinge / Pairs）
- 進去 = 死路
- 「不交友的語音 App」**沒人做**
- 我們**不是別的 App 的競爭者**，我們**創造新類別**

---

## 🏰 競爭護城河

### 為什麼別人不能輕易抄

| 競爭優勢 | 為什麼別人沒做 |
|---|---|
| **語音 + 翻譯字幕** | 純語音 App 沒翻譯，純翻譯 App 沒語音 |
| **隨機 + 不交友** | 隨機 App 都被 Tinder 吃掉，剩下的死掉 (Omegle, Clubhouse) |
| **陪伴 vs 表演** | Clubhouse 是表演，太累；kaitalk 是對話，更親密 |
| **零成本 P2P 架構** | 大公司不會做（要 server cost），小團隊做才划算 |
| **隱私設計** | 對話不存、不錄音、字幕掛斷即清空 |
| **情感連結** | 「想再遇」的浪漫機制，不是冷冰冰的 swipe |

### 護城河不是技術

技術 90% 都是現成的（WebRTC、Web Speech API、翻譯 API）。
**真正的護城河是定位 + 內容 + 社群**：
- 定位：陪伴 + 跨語言
- 內容：豆知識、合作遊戲（之後）
- 社群：「想再遇」帶出的常客生態

## 🌟 為什麼**現在**是對的時機

### 2026 年才能做的事

| 條件 | 2020 年 | **2026 年** |
|---|---|---|
| 中文 STT 準確度 | 70% | **90%+** |
| 日文 STT 準確度 | 75% | **92%+** |
| 即時翻譯品質（中日） | 普通 | **接近人類** |
| 裝置上 AI 翻譯 | 不存在 | **Apple Translation, Chrome Built-in** |
| WebRTC 普及 | 60% 瀏覽器 | **99% 瀏覽器** |
| Capacitor 跨平台 | 早期 | **成熟** |
| 用戶對 AI 翻譯接受度 | 低 | **高（ChatGPT 之後）** |

→ **這個產品在 2024 之前做都會死於翻譯品質**
→ **2026 年才剛好成熟**

### 也是最後的時機？

不是。**還會更成熟**。但：
- 越晚做 = 越多人想到
- 翻譯品質會繼續進步，但**體驗的設計**才是差異化
- 早做 = 早累積用戶 + 早累積數據 + 早建品牌

**現在不做，明年有人做。**

## 💎 北極星指標 (North Star Metric)

不是 DAU，不是收入。是：

### **「跨語言對話成功率」**

> 一通配對中，雙方語言不同，且通話時長 > 5 分鐘的比例

為什麼：
- 這個指標**直接對應產品的存在意義**
- DAU 高但都是同語言聊 → 我們失敗了
- 收入高但跨語言對話 0 通 → 我們失敗了
- 跨語言對話成功率高 → **我們真的解決了問題**

### 次要指標

- **D7 retention**（第 7 天回來率）
- **跨國 connections.matched**（兩人都按「想再遇」且不同國家）
- **Subscription conversion**（免費 → 付費 訂閱率）

## 🚫 我們**不會**做的事

寫下來防止未來自己迷失：

### 1. **不會做交友 / dating**
- 沒有 profile 照片
- 沒有 swipe
- 沒有「附近的人」
- 沒有「我喜歡 / 我討厭」
- 「想再遇」是浪漫不是配對

### 2. **不會做廣告**
- 廣告破壞語音的親密感
- 廣告吸引短期低品質流量
- 訂閱模型勝過廣告模型

### 3. **不會做炫技 AI**
- 我們不會 fine-tune 自己的 LLM
- 我們不會做「AI 陪聊」
- 我們不會做「AI 翻譯員」
- AI 是底層工具，**人才是主角**

### 4. **不會做匿名濫用的溫床**
- 雖然匿名，但**有檢舉、有封鎖、有 report 後台**
- 性騷擾零容忍
- 未成年保護
- 配合執法調查

### 5. **不會做大群組廣播**
- kaitalk 是 1:1
- 之後**最多**開放 1:N 但 N ≤ 4
- 永遠不做「房間 100 人」這種

### 6. **不會堅持某個技術 stack**
- iOS 用 Apple API 比較好就用
- Android 用 Chrome 比較好就用
- 之後 web3 / AR / 視訊 / VR 該換就換
- **產品定位不變，技術隨時代換**

## 🌱 vision 跟現實的距離

```
Vision:
   "會講中文，就能跟全世界聊天"
   全球 30+ 語言、千萬用戶、跨文化橋樑

Reality (2026-04-10):
   - 0 個真實付費用戶
   - 5-10 個朋友試過
   - 只支援中日兩國語言
   - 沒有 OAuth 登入
   - 沒有 iOS App
   - 沒上 Cloudflared 以外的部署
```

**這個 gap 不可怕，可怕的是迷失方向。**

只要**每週一次**回來看這份 vision，
確認自己**沒跑偏**，
**1-2 年後可以走到那裡**。

## 📜 給未來自己的提醒

1. **vision 大，執行小** —— 一次只做一個語言對
2. **產品大於技術** —— 1 個真實用戶 > 100 行漂亮 code
3. **不被功能蒙蔽** —— 加新功能前問「這對核心 thesis 有幫助嗎」
4. **定位是護城河** —— 不要為了短期流量改成「交友」
5. **用戶比投資人重要** —— 先有 100 個喜歡你的用戶，再談投資
6. **保持節奏** —— 一週推一次 commit，比一天 10 個 commit 健康
7. **你 (創辦人) 是第一個用戶** —— 你不愛用，沒人會愛用
