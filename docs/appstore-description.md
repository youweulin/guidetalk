## 日本語

### サブタイトル（30文字以内）
多言語ボイスチャットで世界と話そう

### プロモーションテキスト（170文字以内）
世界中の人とリアルタイム音声通話＋AI翻訳 — 外国語が話せなくても大丈夫！

### 説明
KaiTalk は、母国語のまま世界中の人とボイスチャットできる多言語ソーシャルアプリです。

【主な機能】
• ランダム音声マッチング — ワンタップで世界中の誰かとボイスチャット開始
• AIリアルタイム翻訳 — 音声を自動でテキスト化し、あなたの言語に翻訳
• 音声翻訳（TTS） — 相手の言葉がわからない？音声翻訳をONにすれば、あなたの言語で読み上げます
• トピックマッチング — グルメ、旅行、音楽などのトピックで気の合う人を探そう
• 地域フィルター — 台湾の人と話したい？近くの人と話したい？自由に選べます
• フレンド機能 — 通話中にお互い「また会いたい」を押せば友達に。いつでも再通話

【KaiTalk を選ぶ理由】
• 外国語を学ぶ必要なし — AIがリアルタイムで翻訳
• テキストボットではなく、本物の人との音声会話
• プライバシー重視 — 仮想アバターとニックネーム制、個人情報不要
• 日本語・中国語・英語など多言語対応

あなたの言葉で、世界中の人と話そう。KaiTalk を今すぐダウンロード！
