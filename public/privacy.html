隱私政策 Privacy Policy

最後更新：2026 年 4 月 11 日

1. 我們收集什麼

  • 暱稱、性別、地區、語言偏好 — 用於配對和個人化體驗
  • 匿名帳號 ID — 由 Supabase 產生，不綁定真實身份
  • IP 位址（雜湊處理） — 僅用於地理位置偵測，不儲存原始 IP
  • 通話紀錄 — 僅儲存時間、時長、配對資訊，不錄音

2. 我們不收集什麼

  • 語音內容 — 所有語音走 P2P 直連，完全不經過我們的 server
  • 字幕/翻譯內容 — 在你的裝置上處理，不上傳 server
  • 對話歷史 — 僅儲存在你的裝置（localStorage），不上傳
  • 真實姓名、電話、Email — 我們不要求這些資訊

3. 檢舉時的資料

當你主動按下「檢舉」按鈕時，即代表你授權我們上傳：

  • 最近的文字字幕記錄（約 50 則）作為證據
  • 這是你主動授權的行為，我們不會在未經同意的情況下收集對話內容

4. 資料儲存

  • 帳號資料儲存於 Turso（SQLite 雲端資料庫）
  • 伺服器位於日本東京（Zeabur）
  • 頭像圖片透過 Cloudflare CDN 提供

5. 第三方服務

  • Supabase — 匿名身份驗證
  • ipinfo.io — IP 地理位置查詢
  • Microsoft Edge TTS — 語音合成（付費用戶）
  • Google Translate / MyMemory — 文字翻譯

6. 資料刪除

你可以隨時清除瀏覽器的 localStorage 來刪除本機資料。如需刪除 server 端的帳號資料，請聯繫我們。

7. 未成年保護

KaiTalk 不適用於 13 歲以下的兒童。如果我們發現未成年用戶，將立即停用其帳號。

8. 聯繫我們

如有隱私相關問題，請聯繫：support@kaitalk.app
